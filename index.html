ProSE in the browser

The ProSE app is at timosachsenberg.github.io/prose-web. The site is built from app/ by the Pages workflow (.github/workflows/pages.yml); locally: cd app && npm ci && npm run dev.

The earlier demos of this repository: examples/prose/ (the first ProSE page) and examples/browser/ (the general OpenMS demo, on the site at openms-demo/).
