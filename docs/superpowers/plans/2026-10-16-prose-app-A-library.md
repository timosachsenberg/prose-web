# ProSE app, part A: OpenMS library (merged multi-file evaluation) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the ProSE tool's `-out_merged` evaluation into `ProSEAlgorithm`, so the browser app and native
ProSE pool multi-file results with the same code. Also make the multi-file search report which file it is
on, and record the NCE that PeptDeep calibrated.

**Architecture:** A new public `ProSEAlgorithm::mergeFileResults()` takes over the block of `src/topp/ProSE.cpp`
that pools per-file PSMs, runs `BasicProteinInferenceAlgorithm`, applies picked-protein FDR and removes
decoys. The tool calls it. A characterization TOPP test, written *before* the move, pins the merged
idXML byte for byte (up to the usual whitelist). This follows the pattern of #10578 (Percolator into the
algorithm).

**Tech Stack:** C++20, OpenMS class tests (`START_SECTION`), TOPP tests (CTest + FuzzyDiff), CMake/Ninja.

**Spec:** `docs/superpowers/specs/2026-10-16-prose-app-design.md` (sections "Engine work" and "Settled while reviewing").

  ```cpp
  /// The pooled evaluation of a multi-file search (the ProSE tool's -out_merged).
  struct MergedResult
  {
    std::vector<ProteinIdentification> protein_ids; ///< one pooled run; empty if no file succeeded
    PeptideIdentificationList peptide_ids;          ///< PSMs of all files; meta value 'id_merge_index' = input position
    bool protein_fdr_applied = false;               ///< picked-protein FDR applied and decoys removed
  };
  /// Pools result (moving its identifications out), infers proteins across files, applies FDR:protein
  /// of this instance with picked-protein FDR if decoy proteins were identified. Throws

  MergedResult mergeFileResults(MultiFileSearchResult& result, const StringList& in_spectra_files) const;
  ```
